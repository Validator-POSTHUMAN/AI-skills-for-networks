# Incident gates

## Immediate
- Timestamp and scope recorded
- Double-sign/key/state risk assessed
- Destructive automation frozen if needed
- External validator truth checked

## Recovery
- Evidence preserved
- Smallest reversible action chosen
- Specialist workflow used for migration or snapshot restore
- No key contents or secret-bearing dumps exposed

## Closure
- Height and recent signing verified externally
- Alerts and dependencies checked
- Watch period defined
- Postmortem and durable prevention captured
