# Exit phase gates

## Exit authorization
- Exact chain, environment, validator, and intended outcome
- Chain-specific exit and unbonding rules verified
- Transaction sequence and delegator impact reviewed
- Key backup verified without exposing contents

## Transaction gate
- Human-readable signer, destination, amount, denom, fees, chain ID
- Simulation or unsigned result reviewed when supported
- Explicit approval before signing or broadcast
- On-chain result verified independently

## Decommission gate
- Approved exit state reached
- Signer stop is safe and intentional
- Retention requirements satisfied
- Data deletion separately approved
- Monitoring, routes, inventory, and cost records reconciled
