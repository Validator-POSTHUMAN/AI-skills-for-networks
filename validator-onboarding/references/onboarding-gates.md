# Validator onboarding gates

## Readiness
- Correct chain/environment and official procedure
- Node synced against independent truth
- Signer uniqueness and custody proven
- Key backups verified without secret output
- Capacity, exposure, monitoring, and recovery ready

## Registration
- Immutable parameters reviewed
- Commission and stake explicitly approved
- Simulation/unsigned output checked when supported
- Explicit approval before broadcast or external submission

## Completion
- Published identity and parameters match
- Active/bonded or pending condition externally verified
- Recent signatures or attestations observed
- Monitoring, alerts, backups, and documentation complete
